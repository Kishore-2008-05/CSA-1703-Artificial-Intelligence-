# CSA17 – Artificial Intelligence Assignments (CO1 and CO2)

Python 3 implementations, reproducible experiments, raw result files and task-by-task reports for the two supplied assignments.

- [Assignment 1 – CO1](Assignment-1-CO1/REPORT.md): Hospital Medicine-Delivery Robot, Tasks 1–12.
- [Assignment 2 – CO2](Assignment-2-CO2/REPORT.md): Searching Techniques, Tasks 1–7.
- Existing introductory AI experiment files and screenshots are preserved.

## Run
```bash
cd Assignment-1-CO1
python assignment1.py
cd ../Assignment-2-CO2
python assignment2.py
```
Python 3.10+ recommended; standard library only. The scripts regenerate CSV/JSON results. Operation counts are primary evidence; timings vary by machine. Synthetic maps/graphs are teaching fixtures, not real hospital/campus measurements. Review the source and be ready to explain algorithms and assumptions during viva.
