# Assignment 5 – CO5 (Artificial Intelligence – CSA17)

**Title:** Agents, Intelligent Systems and Real-Time AI: Architecture, Engineering and Deployment  
**Nature:** Individual | **Marks:** 50 (Part A: 25, Part B: 25)

## Repository contents
- `assignment5.py` – runnable standard-library teaching implementation for the drone/grid simulator, swarm experiment, rule-based pump advisor, synthetic edge-model benchmark and retrieval chatbot.
- `REPORT.md` – design answers, pseudocode, assumptions, evaluation plan and limitations.
- `requirements.txt` – no third-party packages required for the baseline implementation.
- `results/` – generated JSON and CSV outputs after execution.

## Environment
- Python 3.10 or later
- Standard library only
- Dataset: deterministic **synthetic** intrusion-like records generated by the program. It is not a public dataset and must not be represented as real-world evidence.

## Run
```bash
python assignment5.py --out results
```

The program writes drone trace, swarm metrics, expert-system results, edge benchmark and chatbot smoke tests.

## Task map
- A1/B1: hybrid drone agent and grid simulator
- A2/B1: decentralised local-rule swarm and multi-seed experiment
- A3/B2: reusable expert-system shell and pump-fault rules
- A4/B3: RDD pipeline design is documented in REPORT.md; PySpark scaling must be run in an environment with PySpark installed
- A5/B3: full-versus-quantized centroid demonstration on a synthetic intrusion benchmark
- B4: retrieval chatbot with eight intents and out-of-scope fallback
