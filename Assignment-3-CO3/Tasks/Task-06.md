# Task 6 – Forward and Backward Chaining

Use an organisation hierarchy with about ten definite-clause rules and 100, 1,000 and 10,000 facts. Implement forward chaining to a fixed point and backward chaining with substitutions. Measure inferred facts, rule firings, redundant derivations, iterations, irrelevant facts, goals, unifications and maximum depth. Demonstrate left recursion and a termination remedy.

## Evidence checklist
- [ ] Design and pseudocode before implementation
- [ ] Manual derivation/trace
- [ ] Reproducible source and inputs
- [ ] Expected versus actual output
- [ ] Operation counts and timing
- [ ] Boundary/failure test and interpretation
