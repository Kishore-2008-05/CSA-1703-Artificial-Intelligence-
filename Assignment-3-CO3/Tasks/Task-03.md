# Task 3 – Knowledge Engineering in First-Order Logic

Model exam eligibility with predicates for student, course, attendance, prerequisites, fees, discipline, approved leave and eligibility. Write at least 12 quantified axioms including an existential. Compare repeated propositional rules (growth O(sc)) with reusable FOL axioms. Create 15 queries: five true, five false and five binding queries; record three KB defects and fixes.

## Evidence checklist
- [ ] Design and pseudocode before implementation
- [ ] Manual derivation/trace
- [ ] Reproducible source and inputs
- [ ] Expected versus actual output
- [ ] Operation counts and timing
- [ ] Boundary/failure test and interpretation
