# Task 7 – Day-4 Hospital Medication-Safety Advisor

Retain two independent design proposals, compare them, then jointly design a FOL knowledge base, vocabulary, indexed/agenda inference and provenance-based explanations. Analyse soundness, completeness and complexity. Test at least 30 dangerous/normal cases at 40, 400 and 2,000 rules; record latency, inference steps, memory and explanation length. Include limitations from uncertainty and missing records.

## Evidence checklist
- [ ] Design and pseudocode before implementation
- [ ] Manual derivation/trace
- [ ] Reproducible source and inputs
- [ ] Expected versus actual output
- [ ] Operation counts and timing
- [ ] Boundary/failure test and interpretation
