# Task 5 – Statistical, Kernel and Explanation-Based Learning

Implement Naive Bayes with Laplace alpha 0, 0.1, 1 and 10 and report classification metrics/log-loss. Compare linear and RBF SVM using five-fold CV, support-vector count and training time against Naive Bayes and the tree. Create six FOL domain rules, an explanation tree, a generalised EBL rule and 20 test cases.
