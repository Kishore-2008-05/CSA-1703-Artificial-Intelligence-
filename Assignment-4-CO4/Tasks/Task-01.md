# Task 1 – Diagnose and Repair a Learning Protocol

List at least five defects in training and testing on the same data. Write explicit pseudocode for stratified train/test separation, k-fold CV model selection, one-time held-out evaluation, metrics and majority baseline. Demonstrate training accuracy optimism on a real labelled dataset.

## Evidence checklist
- [ ] Design and pseudocode before implementation
- [ ] Manual derivation/trace
- [ ] Reproducible source and inputs
- [ ] Expected versus actual output
- [ ] Required metrics and plots
- [ ] Boundary/failure test and interpretation
